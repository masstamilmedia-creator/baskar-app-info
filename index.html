BASKAR One Repository Backup is the Google OAuth application identity used for the owner's desktop backup and File Distribution Desk workflows.

What the desktop application does

The owner selects local files or folders, chooses a local destination or an authorized Google Drive account and folder, reviews the job, and starts the transfer. Google Drive uploads retain local originals and use downloaded SHA-256 checks to verify file contents. Existing repository tools also support explicitly reviewed project publishing to GitHub.

This utility supports project continuity and personal file organization. It is separate from the BASKAR One software product and its unfinished architecture.

Why Google Drive access is requested

Drive access lets the desktop application list the owner's existing folders, place selected files in a chosen destination, and download destination files for duplicate detection and verification. Each Google account must be authorized separately. Account labels and favorites help the owner choose the intended destination.

The requested Drive scope is broad enough to access existing files and folders; it is not technically limited to one favorite folder. The current distribution workflow does not offer automatic cloud deletion or background synchronization.

Personal use

This is an owner-operated desktop tool for the owner's authorized accounts, not a public upload service. This website is an informational page: it does not sign visitors in, connect to their Drive, or accept uploads.
